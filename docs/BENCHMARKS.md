## 3. Критический научный анализ результатов

### 3.1. Почему Exact Recall = 0/5 на произвольных строках?
1. **Превосходство базового априора $W_{\text{base}}$:** Аналитическое решение задачи $\min \|\Delta W X - Y\|_F^2$ строит линейное отображение ранга $r=16$. При делении на ранг ($\alpha/r = 1.0$) амплитуда $\Delta W$ составляет малую долю от нормы базовых весов $\|W_{\text{base}}\|_F$.
2. **Артефакт жадного поиска ($\text{argmax}$):** Жадный декодер на каждом шаге выбирает токен с максимальным логитом. Поскольку перплексия снижается на доли или единицы процентов, базовые токены общего языка по-прежнему имеют больший логит, чем редкая синтетическая строка.
3. **Разрыв между полным вниманием и статической проекцией:** В полном трансформере ключ-значение $K, V$ контекста участвуют в динамической маршрутизации через Softmax от запроса $Q_{\text{query}}$. Статическая матрица $\Delta W$ проецирует входной вектор независимо от селективности запроса.

### 3.2. Почему ускорение TTFT достигает 92x?
- Задержка первого токена в авторегрессионных трансформерах пропорциональна длине входящего префикса (операция Prefill).
- EngramRS исключает контекст из промпта: запрос содержит всего 16–22 токена вместо 2000 токенов. Prefill 16 токенов занимает ~60–230 мс вместо ~6 секунд.
- Это дает реальное пользовательское ускорение интерактивности при фиксированном контексте.

## 4. Воспроизведение бенчмарков

```bash
# 1. Сборка Rust-библиотеки в режиме максимальной оптимизации
cargo test --release -- --nocapture

# 2. Установка Python wheel
python -m maturin develop --release

# 3. Запуск полного тестового пакета
python -m pytest

# 4. Запуск сквозного бенчмарка (требуется GPU с поддержкой CUDA)
python benchmarks/run_complex_comparison.py
```
