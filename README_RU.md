# EngramRS (v0.3.0) — Документация на русском языке

**Экспериментальный исследовательский прототип Zero-Grad компилятора контекста в LoRA-адаптеры на Rust + Python.**  
Проект исследует возможность аналитического сжатия активаций длинного контекста трансформера в низкоранговые весовые адаптеры (LoRA) в замкнутой форме ($\Delta W = Y X^+$) через Dual Woodbury Cholesky и рандомизированный SVD без градиентного спуска (`backward()`).

## 📌 Статус проекта и научная честность

> [!WARNING]
> **Исследовательский статус прототипа:**  
> EngramRS — это **исследовательский прототип**, а не готовая промышленная замена KV-кэшированию или RAG.  
> Бенчмарки на реальной модели `Qwen/Qwen2.5-0.5B-Instruct` показывают, что хотя инъекция аналитических весов LoRA дает измеримое падение перплексии целевого ответа (до **-3.03%** на полносвязных слоях SwiGLU MLP), **Exact Fact Recall (точное воспроизведение факта) при жадном декодировании без контекста в промпте составляет 0/5 (0%)**.  
> Базовое распределение весов $W_{\text{base}}$ превосходит линейное возмущение $\Delta W$, и простая линейная проекция поверх 2000 токенов прозы не способна заменить полноценный механизм внимания ($K, V$).

| Измерение | Полный контекст | KV Prefix Caching (vLLM/SGLang) | EngramRS (LoRA $\Delta W$) |
|---|:---:|:---:|:---:|
| **Exact Fact Recall** | **100% (5/5)** | **100% (5/5)** | **0% (0/5)** (Доминирует базовый prior) |
| **Задержка Prefill (TTFT)** | ~5500 мс (повторный prefill) | **~60 мс** (из кэша) | **~60–95 мс** (контекст стерт) |
| **Память KV-кэша контекста** | 24.94 MiB | 24.94 MiB (удерживается в VRAM) | **0.19 MiB** (только KV вопроса) |
| **Размер адаптера** | 0 MB | 0 MB | 1.85 MiB (FP16) / 3.69 MiB (FP32) |
| **Оверхед компиляции** | 0 мс | 1x prefill | 400 мс (`o_proj`) – 7600 мс (Dual) |

## 🔍 Научный анализ и известные ограничения

1. **Почему Exact Recall = 0/5:**
   - Амплитуда аналитического возмущения $\Delta W$ ранга 16 при коэффициенте масштабирования $\alpha/r = 1.0$ значительно уступает норме весов базовой модели $\|W_{\text{base}}\|_F$.
   - При жадном поиске ($\text{argmax}$) токены общего языка преобладают над специфическими терминами из контекста.
   - Метод учится на активациях $X_{\text{ctx}}$, а на инференсе на вход подается вопрос $X_{\text{query}}$, активации которого лежат в другом подпространстве.
2. **Природа ускорения TTFT:**
   - Ускорение в 13.7x–92.2x раз возникает исключительно из-за **сокращения длины промпта** (16 токенов вопроса вместо 2000 токенов контекста).
   - Компиляция занимает от 0.4 до 7.6 секунд. Если доступна видеопамять, промышленное решение **KV Prefix Caching** (vLLM / SGLang) обеспечивает 100% точность с тем же низким TTFT.
3. **Ротационные эмбеддинги RoPE в Virtual KV-Prefix:**
   - Сжатие контекста в 32 виртуальных токена разрушает гармоническую непрерывность фазового угла RoPE, приводя к зацикливанию текста при авторегрессии. Прямая инъекция в веса LoRA лишена этого дефекта и сохраняет связность языка.

## 📚 Связанные исследования (Related Work)

- **ROME / MEMIT:** Meng et al. (2022, 2023) — аналитическая правка фактов в слоях MLP трансформеров через замкнутую форму решения наименьших квадратов для точечных троек (субъект-отношение-объект).
- **AlphaEdit:** Sun et al. (2024) — проекция в ядро (Null-space projection) для предотвращения забывания фоновых знаний.
- **KV Cache Prefix Caching:** Kwon et al. (vLLM, 2023) — системное повторное использование KV-тензоров без потери информации.

## 🚀 Быстрый старт

```bash
git clone https://github.com/qaddasd/EngramRS.git
cd EngramRS
pip install maturin
maturin develop --release
```

### Экспорт в GGUF для llama.cpp и Ollama

```bash
engram export-gguf --adapter ./engram_adapter --output ./adapter.gguf
```

- **Для llama.cpp:**
  ```bash
  llama-cli -m model.gguf --lora adapter.gguf -p "Question: What is the secret code?\nAnswer:"
  ```
- **Для Ollama:**
  Создайте `Modelfile`:
  ```dockerfile
  FROM qwen2.5:0.5b
  ADAPTER ./adapter.gguf
  ```
  Затем соберите и запустите:
  ```bash
  ollama create my-engram-model -f Modelfile
  ollama run my-engram-model
  ```
